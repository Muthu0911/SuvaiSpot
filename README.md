
# SuvaiSpot – Indian Recipe Discovery App

## About the Project

SuvaiSpot is a React Native recipe discovery application that helps
users explore Indian dishes, view ingredients, follow cooking
instructions, save favorite recipes, and add their own recipes.

## Features

- Browse Indian recipes
- Search by recipe name or ingredient
- Filter recipes by category
- View recipe details and preparation steps
- Save and remove favorite recipes
- Add custom recipes
- Responsive mobile-friendly interface

## Technologies Used

- React Native
- Expo
- JavaScript
- React Hooks
- React Native components
- StyleSheet for styling

## Project Files

- App.js – Main application and screen logic
- recipes.js – Sample recipes and categories
- RecipeCard.js – Reusable recipe card component
- RecipeDetails.js – Recipe information screen
- package.json – Project dependencies and scripts

## How to Run

1. Install Node.js and npm.
2. Install the Expo CLI tools if needed.
3. Install project dependencies using npm install.
4. Start the app using npx expo start.
5. Scan the QR code using Expo Go or run it in a supported emulator.

## Note

Recipes added during a session are stored in application state.
They are not saved permanently after the app restarts.
Recipe images require an internet connection.

## Project Purpose

This project demonstrates React Native UI components, list rendering,
state management, search, filtering, reusable components, and
interactive recipe screens.
